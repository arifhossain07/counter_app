# 🔢 Counter App

A simple, fast, and clean Counter Application built with **Flutter**. This app helps you count efficiently and keep track of your progress using a history log, powered by the **Provider** state management pattern.

## ✨ Features

- **Increment & Decrement:** Easily increase or decrease the counter value with a smooth experience.
- **Save History:** Save your current count to a history list with a single click.
- **Track History:** View all your saved counts along with the exact date and time.
- **Reset Counter:** Quickly reset the counter to zero whenever needed.
- **State Management:** Powered by `provider` for predictable and reactive UI updates.
- **Clean UI:** Simple and intuitive design using Material 3 components and custom action buttons.

## 🚀 Technologies Used

- Flutter & Dart
- provider (State Management)
- intl (Date Formatting)
- Material Design 3

## 🛠️ Installation

1. Clone the repository: `git clone https://github.com/arifhossain07/counter_app.git`
2. Install dependencies: `flutter pub get`
3. Run the app: `flutter run`
